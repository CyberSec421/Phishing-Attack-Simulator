## 🔍 About the Project

This repository showcases a custom-built **Phishing Attack Simulator**, developed as part of my academic cybersecurity journey. It simulates realistic phishing attacks in a **safe, local, and sandboxed** environment—intended purely for awareness, training, and portfolio demonstration.

It includes:
- ✉️ A realistic phishing email generator
- 🌐 A simulated login page mimicking a real-world portal
- 🧾 Credential logging for awareness metrics
- 📊 A simple reporting mechanism to analyze simulated victim responses

> ⚠️ This project is for **demonstration purposes only**. It is not meant to be deployed or executed in production or real-world environments.

## 🧠 My Learning Process

This project demonstrates my ability to:
- Design ethical cybersecurity simulations with **realistic attack models**
- Translate abstract threats into **hands-on technical solutions**
- Build tools that can be used in **awareness training and user education**

I relied on **ChatGPT** to guide me through writing clean, functional Python scripts. This approach allowed me to:
- Understand scripting logic and workflows step-by-step
- Build a tool from scratch with a focus on **cybersecurity awareness**
- Gain hands-on experience working with Flask and email protocols

To ensure ethical and risk-free testing, I used **Mailtrap**, a **sandboxed email delivery platform**, to simulate phishing email campaigns. This avoided any interaction with live mailboxes and protected all participants from unintended exposure.

---

## 📁 Project Highlights

- **Email Generator**: Sends simulated phishing emails using sandbox credentials.
- **Fake Login Page**: Collects test credentials (e.g., username & password) without harm.
- **Credential Logger**: Tracks user inputs to a local file for awareness reporting.
- **Report Generator**: Analyzes how many users interacted with the phishing attempt.
